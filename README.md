## Technologies Behind This Portfolio

Built with HTML5, CSS3, and JavaScript, using Bootstrap 5 for responsive layouts, Bootstrap Icons, AOS for scroll animations, and Typed.js for animated text. Typography is provided by Google Fonts.

The website is static and requires no build step or package installation. To preview it locally, run the following command from the project folder with Python 3 installed:

```sh
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. Save changes and refresh to see updates; press `Ctrl+C` in the terminal to stop the server.
